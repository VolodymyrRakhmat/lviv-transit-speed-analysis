# Lviv Public Transit Speed Analysis

Інструменти для обробки геопросторової телеметрії громадського транспорту Львова, аналізу швидкісних режимів на маршрутах та інтерактивної візуалізації результатів.

## Структура проєкту

* `analyze1.py` — парсинг, очищення та агрегація зібраних даних телеметрії транспорту.
* `speed_map.py` — розрахунок середніх і миттєвих швидкостей руху на ділянках маршрутів та підготовка геоданих.
* `build_site_2.py` — генерація статичної веб-сторінки з інтерактивною картою та аналітичними шарами.
* `index.html` — згенерований веб-інтерфейс для візуалізації швидкісних показників міста.
